===============================================================
 DANYAL'S RIG BUILDER  v1.0.2
 Free auto-rigging toolset for Autodesk Maya (2022 to 2026)
===============================================================

 INSTALL  (30 seconds)
 ---------------------
 1. You have already extracted this folder. Good - Maya cannot
    run the tool from inside the .zip.

 2. Open Maya.

 3. Drag the file  install.py  from THIS folder onto an open
    Maya viewport (the 3D area), and let go.

 4. A button labelled "DR" / "Danyal's Rig" appears on your
    current shelf. Click it. The Rig Builder opens.

 That's it. The button stays there next time you open Maya.

 Do NOT move, rename or delete the "installation_files" folder
 before you install - the installer copies the tool from it.

 FIRST RIG IN 60 SECONDS
 -----------------------
 1. Click the DR shelf button.
 2. Create Guides.
 3. Drag the guide locators onto your model (left side only),
    then Mirror L to R.
 4. Build Rig.
 5. Select your mesh, then Auto-Skin Everything.
 You now have a posable, skinned rig.

 ---------
 In Maya's Script Editor (Python tab), run:
